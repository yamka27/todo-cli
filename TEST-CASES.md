# Тест-кейси для Todo CLI

---

## TC-001: Додати задачу з усіма параметрами

**Передумови:** Файл даних відсутній

**Кроки:**
1. `npm run reset`
2. `npm run todo -- add "Тестова задача" --priority high --due 2026-12-31 --tag test`

**Очікуваний результат:**
- Вивід: `✓ Додано #1: Тестова задача`
- Exit code: 0
- Файл `D:/test/todos.json` створено

**Статус:** #TC-001

---
